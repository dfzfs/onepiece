# 원피스 시뮬봇 HUD (ST-OnePieceSim)

대해적시대 하드코어 시뮬봇 **「원피스 시뮬봇」** 전용 SillyTavern 확장입니다. (팬메이드 · 비공식)
체력·격·베리·현상금·악명·위험도·명성·부상·동료·인연을 **확장이 직접 계산**하고, 상태창(HUD)·출항 창·지도·신문·의뢰 게시판·판정·생존/회귀·수감/타임스킵을 제공합니다.

AI는 응답 끝에 이번 턴의 **변화량만** 적습니다. 숫자는 확장이 지킵니다.

```
<state>
hp: -18
heat: +15
loc: 로그타운 · 처형대 광장
foe: 해군 대령 스모커 | 3 | 85 | 연기 — 잡히지 않는다
wound: +왼쪽 어깨 자상
</state>
```

## v2.0 — 루트와 취향

- **빠른 시작 시나리오 9종**: 출항 창 맨 위. 밀짚모자의 새 동료 / 로그타운의 신병 / 샤본디의 작은 술집 / 하트의 선의 / 혁명의 불씨 / 가면 아래의 요원 / 초열지옥에서 눈을 뜨다(수감 상태로 시작) / 로저가 죽은 날 / 크로스 길드의 막내. 누르면 시대·진영·소속·섬·특기·꿈·목표·톤·난이도가 채워지고, 전부 고칠 수 있습니다.
- **서술 취향**: 톤(왕도 모험·느긋한 일상·로맨스·코미디·시리어스) · 시점(2인칭·3인칭·1인칭) · 분량 · 연애 속도(없음·아주 천천히·보통·빠르게). 채팅마다 따로 저장되고 언제든 바꿀 수 있습니다. 연애 "없음"이면 설렘 수치가 아예 오르지 않습니다.
- **이명(異名)**: 현상금이 걸리거나 신문 1면에 오르면 세상이 이명을 붙여 줍니다(`epithet:`). 수배서와 상태창에 함께 표시. 직접 정할 수도 있습니다.
- **전향**: 탈영·입대·추방으로 진영이 바뀝니다(`faction: 진영 | 소속 | 직책`, 또는 시트 › 관리 › 진영 바꾸기). 게이지는 0부터, 예전 인연은 그대로 — 해군에서 해적으로, 해적에서 혁명군으로.
- **🤝 약속**: 누군가에게 한 약속을 기록(최대 6개). 지키면 신뢰 +10, 어기면 −15. AI도 약속을 기억합니다.
- **🔧 숙련**: 요리·낚시·의술·노래 같은 생활 기술 0~5(최대 6개). 연습하면 오르고, 같은 이름의 판정에 보너스. 출항 때 고른 특기가 첫 숙련이 됩니다.
- **🏅 업적 35종**: 탐험·이름·인연·꿈·고난. 걸어온 길에 따라 다른 것이 열립니다. 앨범 탭.
- **인연의 근황**: 떨어져 있는 인연이 지금 어디 있는지(`where:`) 기록되고, 지도에 ♡로 표시됩니다.
- **📖 항해 수첩**: 수배서·이명·꿈·통계·인연·업적을 한 장에 모은 요약 카드(캡처용) + 「에필로그 쓰기」.
- **상태창 색 4종**: 심해 · 흑단 · 포도주 · 숲.
- **최적화**: 주입문을 둘로 나눠 동료·인연 이름이 섬 로어북을 매 턴 켜지 않게 했습니다. "규칙 주입: 간결" 설정(형식 예시·수치 기준 생략). 메시지 카드의 알림이 4건을 넘으면 접힙니다.
- **수정**: 새 항해를 시작해도 이전 편지·메모·섬 소문이 남던 문제.
- 새 키: `epithet` `promise` `skill` `where` `faction`. 새 명령: `/op-card`.

## v1.4 — 플레이 피드백 반영

- **원작 캐릭터 AI 자동 채우기 확장**: 이름만 쓰고 누르면 소속·직책·격·현상금·열매·패기·위치·사연에 더해 **꿈·베리·배·동료(최대 9명)·주요 인연(최대 6명, 신뢰 포함)·소지품**까지 대략 채웁니다. 그다음 직접 고치면 됩니다. 원작 캐릭터로 시작하면 "처음부터"가 아니라 그 시점 한가운데서 시작합니다.
- **버그 수정**: 루피(선장)로 들어가면 "몽키 D. 루피 · 선장" 인연이 자기 자신으로 붙던 문제.
- **직접 입력 확대**: 세부 시점, 동료, 소지품, 목표, 열매 계통, 활동(직접 쓰기), 판정 종류(기타), 판정 상대, 소지품·배 개조·앨범 직접 추가, 해프닝 직접 만들기, 편지 받는 사람.
- **라이트 테마 대응**: 메시지 상태 카드·선택지·팝업이 항상 자체 어두운 바탕을 갖습니다(흰 바탕 + 노란 글씨 문제 해결).
- **뺀 것**: 관계도(방사형 그림), 챕터 요약.
- **✉️ 편지 (뉴스 쿠 우편)**: 짧게 써서 보내면 상대가 자기 말투로 답장. 12% 분실, 8% 엉뚱한 사람에게 배달(모르는 사람이 답장), 15% 하루~사흘 늦게 도착. 메신저처럼 상대별 대화. NPC도 먼저 편지를 보냅니다(`letter: 이름 | 내용`). 주고받은 편지는 AI가 기억.
- **📝 메모장**: 할 일 · 오늘의 기록 · 메모. "AI 반영" 켠 것만 AI에게 전달(최근 6개). 할 일은 완료 체크, 기록은 앨범 추억으로도 남기기.
- **🌀 해프닝 (랜덤 저주)**: 고양이가 됨, 영혼 체인지, 사랑의 묘약, 거울 속 타인, 배가 뒤집힘 등 21종(웃김·로맨스·공포·재난·이상). 날짜가 바뀔 때 가끔 자동(끔/가끔/종종), 버튼으로 랜덤·종류별·직접 만들기. 판정 보정과 기간이 있습니다.
- **🎲 매력 판정**: 매력·교섭 판정에 상대를 고르면 관계가 목표를 바꿉니다(낯선 사이 −15, 설렘·신뢰 +, 적의 −20). 「고백한다」는 설렘 60 전엔 −35까지. 실패하면 마음이 움직이지 않고, 대실패는 어색한 후퇴.
- **해적·능력자가 아닐 때**: 해군·정부·시민은 상태창에 현상금 대신 계급/직업, 진영별 활동(순찰·보고서·접선·가게 일…), 진영별 일상 지침. 능력자가 아니면 "헤엄칠 수 있다" 항해 +5, 맨몸의 길을 멋있게 그리라는 지침. 해군·정부는 조선소 대신 배정 함선.
- **기능 켜고 끄기**: 확장 설정 › 기능 켜고 끄기 — 활동, 편지, 메모장, 해프닝, 게시판, 신문, 생일·기념일, 섬 소문, 앨범. 끈 기능은 버튼도 프롬프트 지시도 빠집니다.
- 상단 버튼 정리: 🏝️ 활동 · ✉️ 편지 · 🎲 판정 · ⋯ 더 보기.

## v1.3 — 지도 · 달력 · 배 · 챕터

- **그림 지도**: 레드라인 × 위대한 항로 × 네 바다, 섬 45곳. 상륙한 섬은 금색, 지나온 항로는 점선, 지금 섬엔 배. 섬을 누르면 정보·이 시대의 소문·이곳으로 향한다. 모바일은 가로 스크롤.
- **시대별 원작 핵심 인물(10명 이내)**: 그 시대 시작 시점에 어느 섬에 누가 있는지 지도에 작은 점과 이름으로 표시(토큰 0).
- **달력**: 출항하는 날(월/일)을 정하면 날짜가 흐릅니다. 원작 인물 30명의 공식 생일, 내 생일, 연인·관계 있는 인연과 만난 지 100일마다 이벤트.
- **수배서 사진**: 출항 창에 이미지 주소를 넣거나, 비우면 페르소나 아바타를 씁니다(세피아 처리).
- **조선소**: 새 배 4종 구입, 개조 8종(보강 선체 = 선체 손상 절반, 의무실 = 배 위 생존 판정 +10, 측면 외륜 등).

## v1.2 — 최적화 · 모델 선택

- **인원 상한**: 인연 최대 10명, 동료 최대 10명. 넘치면 가장 옅은 인연부터 정리(연인·동료·관계 이름이 있는 사람은 지킴), 동료는 자리가 없다고 알림. AI에게도 "이름 붙은 인물은 적게" 지시.
- **기록 상한**: 추억 30 · 발견 40 · 뉴스 20 · 항해일지 80 · 회귀 지점 15. 프롬프트에 들어가는 인연은 상위 6명만.
- **재계산 최적화**: 직전 스냅샷을 재사용해 복제를 절반으로 줄임(600턴 재계산 약 0.1초).
- **이름 맞추기 수정**: "로"와 "로빈"이 같은 사람으로 합쳐지던 문제 수정("로" = "트라팔가 로"는 유지).
- **확장 AI 모델 선택**: 설정 › "확장 AI에 쓸 모델". 실리태번 「연결 프로필」에 저장한 프로필을 고르면 의뢰 게시판·신문·섬 소문·AI 캐릭터/열매 생성이 그 모델로 갑니다. 롤플 본문은 메인 연결 그대로. 실패하면 메인 연결로 자동 대체.

## v1.1 — 탐험 · 관계 · 인생 시뮬 강화

- **인연 두 줄**: 신뢰(−100~100)와 설렘(0~100)을 따로 셉니다. 설렘 15 신경 쓰임 → 35 설렘 → 60 사랑 → 85 깊은 사랑. 문턱을 넘으면 AI가 작은 장면으로 보여 줍니다(60 전에는 고백 금지).
- **인연 상세 창**: 이름을 누르면 신뢰·설렘·함께한 추억, 만나러 간다·연락·선물, 관계 이름 직접 정하기.
- **🏝️ 오늘 뭐 하지?**: 섬(명물 먹기·술집·시장·탐험·수련·일하기·쉬기·함께 시간·선물·연락·연회·일기), 항해(낚시·밤 당번·갑판 연회·배 손질·대화), 수감 중 활동. 토큰 0.
- **꿈 ⭐**: 출항 때 정하는 꿈. 진짜 한 걸음마다 차오르고 25·50·75·100%에서 이야기가 반응.
- **앨범**: 추억(폴라로이드), 발견(요리·명소·생물·보물·전설…), 상륙한 섬 n/45. 처음 상륙한 섬은 첫인상 장면.
- **지도 👂**: 그 시대 그 섬의 분위기·명물·지금 있는 원작 인물·소문을 AI가 알려 줌(채팅별 저장).
- **시작 인연**: 출항 때 "나미=소꿉친구"처럼 입력. 소속의 선장·상관은 자동으로 인연이 됨.
- GM 지침과 로어북이 전투보다 탐험·일상·관계 중심으로 바뀜. 새 키: `love`, `memory`, `discover`, `dream`.

## 설치

1. SillyTavern → 확장(블록 아이콘) → **Install extension** → 이 저장소 주소 입력
   `https://github.com/YOUR-ID/ST-OnePieceSim`
2. 캐릭터 카드 `원피스시뮬봇.png`를 가져옵니다. 처음 열 때 **캐릭터 정규식 허용**을 누르세요(정규식 4개가 카드에 들어 있습니다).
3. 로어북은 카드에 내장되어 있습니다. 따로 쓰려면 `원피스시뮬봇_로어북.json`을 월드인포로 가져오세요.
4. 채팅을 열면 **출항** 창이 뜹니다. 정하고 첫 행동을 보내면 시작됩니다.

> 확장은 기본적으로 **원피스 시뮬봇 카드에서만** 켜집니다(카드의 `extensions.onepiecesim` 표식). 다른 카드에 쓰려면 설정에서 "모든 캐릭터에서 사용"을 켜세요.

메시지마다 그 턴의 변동(체력, 베리, 교전, 새 인연, 동료 합류…)이 작은 카드로 붙고, 현상금이 오르면 **수배서**가 붙습니다.

## 규칙 요약

- **격(格)** 1 잡졸 · 2 루키 · 3 실력자 · 4 강자 · 5 괴물 · 6 정점. 적과의 격 차이 × 12가 힘·기술·민첩·의지 판정에 더해짐(최대 −48). 두 단계 위는 정면으로 못 이긴다.
- **게이지** 해적·혁명군 = 악명, 해군·정부 = 공적, 시민 = 명성. 100이 차면 → 현상금 갱신(격에 따라 상승폭) / 진급 / 명성 상승.
- **위험도 ★** 현상금 1 · 5,000만 · 2억 · 10억 · 30억에서 하나씩. ★가 오르면 경보가 뜨고 추격자가 강해진다(★5 버스터콜·대장급).
- **최종장 해군**: 이름이 알려지면 크로스 길드가 당신 목에 현상금을 건다.
- **랜덤 이벤트**: 날짜가 넘어갈 때 확률로 발생(폭풍, 해왕류, 해군 순찰선, 현상금 사냥꾼, CP 요원, 대장 출격 소문, 버스터콜 경보, 호외…). 위험도가 높을수록 자주.
- **체력 0** → 빈사 → **생존 판정**(낭만 100 · 표준 45 · 하드코어 30, 의사 동료 +15). 살아도 확률로 **영구 손상**(눈·손가락·다리·팔…). 실패하면 사망.
- **사망**: 표준 = 도착했던 섬 중 하나로 **회귀**(기억 유지, 재산·부상·관계는 그 시점으로), 하드코어 = 끝. 회귀할수록 생존 판정이 어려워진다.
- **수감** (`prison: 임펠다운 LV4`): 재산 몰수(낭만은 절반), 소지품·배 압수, 동료 흩어짐, 해루석. → **탈옥 시도**(층별 난이도) 또는 **형기를 견딘다**(타임스킵, 다음 시대로 넘어가기 선택 가능).
- **타임스킵**은 시트 › 관리에서 언제든(2년 수련 등).

## 작동 방식

- 상태는 저장된 값이 아니라 **채팅 처음부터 모든 AI 메시지의 `<state>`를 다시 읽어** 계산합니다. 스와이프·수정·삭제하면 자동으로 맞춰집니다.
- 수동 조정(구입, 생존 판정, 회귀, 타임스킵, 시트 수정)은 채팅 메타데이터에 "몇 번째 메시지 시점"과 함께 기록되어 같은 순서로 재생됩니다.
- 새 섬에 도착할 때마다 회귀 지점이 자동으로 생깁니다.
- 현재 상태는 `setExtensionPrompt`로 채팅 깊이 1(설정 가능)에 시스템 메시지로 주입됩니다. `#MODE_…`, `#ERA_…`, 섬 이름이 로어북 항목을 자동으로 켭니다.
- 프롬프트 정규식이 오래된 메시지의 `<state>`·`<choices>`를 지워 토큰을 아낍니다(최근 것은 형식 예시로 남김).

## 문제 해결

- **상태 카드가 안 보이고 `<state>` 글자가 그대로 보임** → 캐릭터 정규식이 꺼져 있습니다. 정규식 확장에서 "원피스 시뮬봇 ①~④"를 허용하거나 `regex` 폴더 JSON을 전역으로 가져오세요.
- **AI가 상태 블록을 빼먹음** → "주입 프롬프트 보기"로 확인하고, 주입 깊이를 0으로 낮춰 보세요.
- **수치가 이상함** → 시트 › 관리 › "마지막 수동 조정 되돌리기", 또는 해당 AI 메시지를 수정하면 즉시 다시 계산됩니다.
- 그 밖의 오류는 브라우저 콘솔(F12)에서 `[원피스 시뮬봇]`으로 시작하는 줄을 확인하세요.
